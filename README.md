Stride - Driver Financial & Mileage Tracker

Stride is a professional-grade progressive web application (PWA) designed specifically for Malaysian drivers and gig economy workers to track daily earnings, operational costs, and vehicle maintenance with ease.

Key Features:
Financial Analytics: Real-time visual performance charts (Chart.js) comparing Gross Income vs. Net Profit.

Malaysian Context: Localized car database (Perodua, Proton, etc.), currency (RM), and official compliance tracking (Roadtax, Insurance, and PUSPAKOM inspections).

Maintenance & Odometer Tracking: Automated maintenance fund calculation (RM0.05/km) and service logs with receipt storage.

Target Management: Daily income goals and monthly mileage progress trackers.

Data Portability: Full JSON backup/import and CSV report export.

Tech Stack:
Vanilla JavaScript, Tailwind CSS, Chart.js, and LocalStorage for offline-first data persistence.
